# CS50P: Introduction to Programming with Python

This repository contains my problem sets and final project for Harvard University's CS50P. Completing this course required writing, testing, and debugging dozens of Python programs, providing me with practical, hands-on experience in software development fundamentals.

## Topics Covered & Applied
* **Functions & Variables:** Defining functions, passing parameters, and managing variable scope.
* **Conditionals & Loops:** Implementing logic and control flow using `if`/`else`, `while`, `for`, and `match-case`.
* **Exceptions:** Handling runtime errors and ensuring program stability with `try` and `except`.
* **Libraries:** Utilizing standard Python modules (`sys`, `csv`, `random`) and integrating third-party packages.
* **Unit Testing:** Writing and executing automated tests using `pytest` to verify code functionality and handle edge cases.
* **File I/O:** Reading, writing, and updating `.txt` and `.csv` files programmatically.
* **Regular Expressions:** Validating user input and extracting data patterns using the `re` library.
* **Object-Oriented Programming (OOP):** Designing custom classes, managing attributes, and writing instance methods.

## Repository Structure
* **`pset0` to `pset8`**: Solutions to the weekly problem sets, progressing from simple scripts to multi-file programs and automated test suites.
* **`final_project`**: Source code and documentation for my capstone project, the **Virtual Grocery Market POS**—a command-line Point of Sale system designed to process items, handle varying weight units, and calculate totals.
